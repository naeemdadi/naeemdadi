## Featured Work

### PR Impact Analysis

Evidence-first GitHub App for pull-request review.

- Builds deterministic JavaScript/TypeScript dependency graphs for PR base/head SHAs.
- Traces changed files through resolved imports, framework routes, APIs, and tRPC
  bindings where impact can be statically proven.
- Uses GPT only after graph evidence is established, with structured output validation
  so AI can explain impact but cannot invent routes or dependencies.
- Posts one sticky GitHub PR comment with source-grounded verification guidance.

Links: [Live demo](https://impact-analysis-yiyj.onrender.com) ·
[GitHub](https://github.com/naeemdadi/impact-analysis)

### Insomanager / Appvocard

AI-powered case-management platform for German insolvency and debt-counseling workflows.

- Built a distributed OCR/LLM extraction system across a Next.js app and a separately
  deployed Express AI service.
- Used BullMQ, Redis, fire-and-forget callbacks, dynamic per-environment response URLs,
  and Server-Sent Events for live job progress.
- Designed a multi-claim extraction pipeline that turns scanned creditor PDFs into
  structured, human-verifiable claims.
- Added AI usage and cost tracking across OpenAI, Azure Document AI, and Google Document
  AI.

Link: [insomanager.vercel.app](https://insomanager.vercel.app/)
